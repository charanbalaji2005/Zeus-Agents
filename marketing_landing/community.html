Ways to contribute

  1. Report a bugRun zeus doctor, then open an issue with its output and the steps that reproduce the problem.
  2. Share a skillSkills are plain Markdown in skills/. Open a pull request with yours so everyone can use it.
  3. Build a pluginAdd tools, hooks, commands or model providers without touching the core. See plugins/ for examples.
  4. Improve the docsFix a typo, clarify a step or add a guide. Small pull requests are welcome.

Community guidelines

  • Be kind and assume good intent. Everyone here is learning.
  • Keep issues focused: one problem or idea per issue.
  • Never post API keys, tokens or passwords, including in logs.
  • Report security problems privately to the maintainer on Discord, never in a public issue.
  • Credit others' work when you build on it.
  • No spam, harassment or self-promotion unrelated to Zeus.
