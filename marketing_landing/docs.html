1. Installation & Setup

Linux • macOS • Windows • pip

Choose your operating system below to copy the one-line terminal installer command:

curl -fsSL https://raw.githubusercontent.com/charanbalaji2005/Zeus-Agents/main/scripts/install.sh | bash

Provisions the isolated PM environment into ~/.zeus, installs dependencies, and creates the global zeus executable in your PATH.

curl -fsSL https://raw.githubusercontent.com/charanbalaji2005/Zeus-Agents/main/scripts/install.sh | bash

Supports Apple Silicon (M1/M2/M3/M4) and Intel Macs on macOS 12 Monterey or newer.

irm https://raw.githubusercontent.com/charanbalaji2005/Zeus-Agents/main/scripts/install.ps1 | iex

Run in PowerShell. Provisions the Python virtual environment and sets user PATH automatically.

pip install git+https://github.com/charanbalaji2005/Zeus-Agents.git

Requires Python 3.10+ and git. Installs the zeus CLI directly into your active virtual environment.

2. How Zeus Works

Core Invariants

Zeus is engineered with a narrow core waist while capability lives at the edges:

• Sacred Prompt Caching

Past context prefixes are never modified, reloaded, or mutated mid-session. Preserving the cached prefix multiplies token speed and slashes inference costs.

• Autonomous Skill Creation

When solving novel tasks, Zeus writes and validates its own reusable SKILL.md modules, compounding knowledge across sessions.

• Persistent SQLite & FTS5 Memory

All conversations, facts, and code context persist locally in ~/.zeus using SQLite trigram full-text search indexing and vector embeddings.

• Multi-Platform Messaging Gateway

A single running gateway daemon connects your agent core to Discord, Telegram, Slack, WhatsApp, Signal, and the terminal simultaneously.

3. CLI Commands Reference

Terminal Subcommands
Command Category Description
zeus Interactive Launch the interactive conversation REPL terminal.
zeus "summarize git diff" One-Shot Execute a task non-interactively and print the result.
zeus status System Display active LLM model, default provider, gateway state, and jobs.
zeus doctor Diagnostics Run full environment audit: Python runtime, SQLite WAL mode, external tools, and packages.
zeus model Models Interactive model picker to switch between Claude, OpenAI, Groq, Gemini, or local models.
zeus auth list Auth Inspect all active credentials, priorities, and token pools.
zeus auth add <provider> --api-key <KEY> Auth Add credentials for Anthropic, OpenAI, Groq, OpenRouter, or Gemini.
zeus tools list Tools Show built-in toolsets (web, browser, file, terminal, code_execution, vision, etc.).
zeus gateway Gateway Start the multi-platform messaging gateway daemon.
zeus cron list Automation List background natural-language scheduled jobs and executions.
zeus update System Check for updates and pull the latest release from git automatically.
zeus --version Info Print the active Zeus Agents version and Python environment facts.

4. In-Session Slash Commands

REPL Shortcuts
/help

Display the in-session command palette, shortcuts, and current session ID.

/skills

Inspect installed skills, browse optional skills, or teach the agent a new skill.

/memory

Search and browse persistent memories stored across past sessions.

/model

Switch the inference LLM on the fly without restarting your session.

/compact

Summarize and compress historical turns to free up context window space.

/clear

Reset the conversation turn history while keeping long-term memories intact.

5. Model Providers & Free Keys

Private & Secure

Zeus supports all major LLM providers natively. Configure credentials via CLI or your ~/.zeus/.env file:

# Configure Anthropic Claude: zeus auth add anthropic --api-key sk-ant-... # Configure OpenAI (GPT-4o / o1): zeus auth add openai --api-key sk-proj-... # Configure Groq (Free high-speed Llama 3): zeus auth add groq --api-key gsk_... # Configure Google Gemini (Free tier): zeus auth add gemini --api-key AIzaSy... # Configure OpenRouter (200+ models): zeus auth add openrouter --api-key sk-or-...
