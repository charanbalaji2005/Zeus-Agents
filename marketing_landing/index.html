Zeus CLI Documentation

Zeus is currently available as a high-performance personal AI agent for your terminal. Download the CLI across Linux, macOS, or Windows, learn how its prompt-caching engine works, and explore all essential commands.

1. Install Zeus CLI Linux • macOS • Windows

Choose your operating system below to copy the one-line terminal installer command:

curl -fsSL https://raw.githubusercontent.com/charanbalaji2005/Zeus-Agents/main/install.sh | bash

Installs dependencies, sets up the isolated PM environment in ~/.zeus, and creates the global zeus binary executable.

curl -fsSL https://raw.githubusercontent.com/charanbalaji2005/Zeus-Agents/main/install.sh | bash

Works with Apple Silicon (M1/M2/M3/M4) and Intel Macs on macOS 12 Monterey or newer.

irm https://raw.githubusercontent.com/charanbalaji2005/Zeus-Agents/main/install.ps1 | iex

Run in PowerShell (Admin recommended). Automatically provisions the virtual environment and sets user PATH.

pip install git+https://github.com/charanbalaji2005/Zeus-Agents.git

Requires Python 3.10+ and pip. Installs the zeus command directly into your active Python environment.

2. How Zeus Works Core Architecture

Zeus is built around a narrow core waist with autonomous capabilities living at the edge:

  • • Hot Prompt Caching: Turn loop invariants guarantee the context prefix stays intact. Mutating history or rebuilding prompts mid-conversation is banned to preserve caching and reduce LLM token costs.
  • • Autonomous Skill Creation: When solving novel problems, Zeus writes and validates its own reusable SKILL.md modules, compounding what it knows for future tasks.
  • • Persistent Vector & FTS5 Memory: All conversations, facts, and code context persist locally in ~/.zeus using SQLite full-text trigram indexing and vector embeddings.
  • • Multi-Platform Gateway: One running daemon connects your agent core to Discord, Telegram, Slack, WhatsApp, Signal, and the terminal simultaneously.
3. CLI Commands Reference CLI • Terminal REPL
Command Category Description
zeus Execution Launch the interactive terminal conversation REPL.
zeus "summarize git changes" One-shot Execute a task non-interactively and print the result.
zeus login Auth Sign your terminal in with your Zeus Agents Google account.
zeus auth add <provider> --api-key <KEY> Auth Add credentials for OpenAI, Anthropic, Groq, OpenRouter, Gemini, or Bedrock.
zeus auth list Auth Inspect all active credentials, priorities, and quota pools.
zeus model Models Interactive model picker to switch the active LLM engine.
zeus gateway Gateway Start the multi-platform messaging gateway daemon (Telegram, Discord, Slack).
zeus cron list Automation List background natural-language scheduled jobs.
zeus tools list Tools Show built-in toolsets, sandboxes, and connected MCP servers.
zeus update System Check for updates and pull the latest release from git automatically.

Features

#1 Connect

Lives Everywhere

Telegram, Discord, Slack, WhatsApp, Signal, Email, CLI — and a growing list of platforms. One agent, one memory, every surface.

#2 Remember

Persistent Memory

It learns your projects, auto-generates skills, and never forgets how it solved a problem.

#3 Schedule

Focused Automation

Natural-language scheduling for reports, backups, and briefings — running unattended through the gateway, focused every time.

#4 Delegate

Tasks Multiplied

Isolated subagents with their own conversations, terminals, and Python RPC scripts for zero-context-cost pipelines.

#5 Search

Browse the Web

Web search, browser automation, vision, image generation, text-to-speech, and multi-model reasoning.

#6 Experiment

Isolated Sandboxing

Five backends — local, Docker, SSH, Singularity, Modal — with container hardening and namespace isolation.
